# Data
This directory contains publicly available sequencing data that can be found on NCBI.

## genomic_resources/

This directory contains genomic resources for the N2 reference strain available at CaeNDR or WormBase.

### Contains
- `20250625_c_elegans_divergent_regions_strain.bed`
	- Hyper-divergent regions in the N2 reference genome among 684 *C. elegans* isotype reference strains. 
- `c_elegans.PRJNA13758.WS283.genome.fa` - publicly available at WormBase.
	- WormBase N2 reference genome assembly version WS283.
- `N2.WS283.cleaned.fa.fai`
	- FASTA index file for WormBase N2 reference genome assembly.
