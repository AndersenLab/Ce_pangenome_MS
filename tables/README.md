# Tables
This directory contains all supplementary tables.

- `wild_strain_genome_stats.tsv`
	- Supplementary Table 1: C. elegans wild strain genome assembly statistics.
- `strain_SVs_cum_length.tsv`
	- Supplementary Table 2: Cumulative length of wild strain structural variants.
- `IPR_genes_overlapSVs.tsv`
	- Supplementary Table 3: Most abundant IPR terms for genes that overlap with SVs.
- `hawaiian_strain_PCA_SVs.tsv`
	- Supplementary Table 4: SVs that are unique to 19 Hawaiian strains that cluster in PCA.
- `all_OGs_matrix.tsv`
	- Supplementary Table 5: Orthogroups among 142 strains of C. elegans.
- `liftedover_WS_HDRs.tsv`
	- Supplementary Table 6: Wild strain HDR coordinates after lift-over.
- `wild_strain_genes_inHDRs.tsv`
	- Supplementary Table 7: Wild strain genes in HDRs.
- `WS_HDR_liftover_finalstats.tsv`
	- Supplementary Table 8: Statistics of wild strain HDRs and the genes contained in them.
- `IPR_annotation_142strains.tsv` - Large file. Publicly available on AWS.
	- Supplementary Table 9: IPR annotations of 142 C. elegans strains.
- `enriched_IPR_inHDRs.tsv`
	- Supplementary Table 10: Enriched IPR terms in wild strain HDRs.
- `IPR_terms_forGeneClass.tsv`
	- Supplementary Table 11: Gene family classifications from IPR descriptions.
- `genotype_matrix.tsv`
	- Supplementary Table 12: Genotype matrix of strains used in genome-wide association mapping.
- `mapping_2018GWAS_MLs.tsv`
	- Supplementary Table 13: Macrocyclic lactone resistance trait file used for genome-wide association mapping.
- `abamectin_q90.TOF_ctrl-regressed_loco.gwa`
	- Supplementary Table 14: Genome-wide association mapping of abamectin q90 TOF.
- `QTL_annotated_SNVs.tsv`
	- Supplementary Table 15: Annotation of shared SNVs across resistant strains.
- `CE_HC_orthology.tsv`
	- Supplementary Table 16: Orthology of *C. elegans* genes associated with abamectin resistance with *H. contortus*.
